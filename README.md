# Brick Strike 2.9: сервер сетевой игры

Сервер для кнопки «Играть» в игре Brick Strike: командный бой (с ботами, которые добирают команды), закладка бомбы,
рейтинговые матчи «Рейтинг 2×2» с таблицей лучших и пати с друзьями. Написан на чистом Node.js, ставить пакеты не нужно. Подойдёт Node.js 12 и новее.

**Этот сервер пускает игру версии 2.7 и новее, а игра 2.7 заходит только на сервер 2.7.** В 2.7 карта «Старый город»
стала в полтора раза больше: у старой игры и у старого сервера другие стены и другое место точки A, вместе они
работать не могут. Игре старше 2.7 сервер откажет во входе и попросит обновиться; игра 2.7 на старом сервере
напишет, что сервер нужно обновить. Поэтому обновляй сервер и раздавай новый APK в один день.

Если сервер уже запущен, для обновления достаточно заменить `server.js` и перезапустить его (`pm2 restart brick-strike`
или `systemctl restart brick-strike`). Файл `ratings.json` трогать не нужно: рейтинг сохранится.

## Что нового в 2.9

- **Радиус взрыва бомбы больше.** Полная сила у бомбы, дальше плавно слабее: ближе примерно 560 единиц не выживает
  никто (без брони около 650), ранит до 1100. Броня теперь смягчает и взрыв, как в игре без интернета.
- Больше ничего не менялось: игры 2.7, 2.8 и 2.9 работают с этим сервером, а игра 2.9 и со старым сервером 2.7
  (только взрыв там будет прежним). Для обновления замени `server.js` и перезапусти сервер.

## Что было в 2.7

- **Большой «Старый город».** Точка A на новом месте, раунд с бомбой длится 1 минуту 55 секунд (было 1:40).
- **Оружие на земле.** У убитого выпадает ствол, который был у него в руках, вместе со скином. Сервер помнит, где он
  лежит, и отдаёт его первому, кто попросил, стоя рядом. Подобранный ствол чужой стороны (AK-47 у спецназа)
  наносит урон до смерти игрока. В бою с возрождением оружие лежит 25 секунд, в раундах с бомбой до конца раунда.
  Своё оружие игрок может выбросить сам (клавиша G, на телефоне кнопка в окне «Оружие»), чтобы его взял друг.
- **«Сейчас играют».** Игра в меню получает от сервера список общих боёв, где есть люди и есть место, и может зайти
  в выбранный. Свои комнаты (имя ввели сами игроки) и рейтинговые матчи в этот список не попадают.
- **Перчатки админа.** Их видят другие игроки только у того, чья игра назвала серверу ключ админа. Ключ получается
  в игре из секретного кода; в `server.js` лежит только число `ADMIN_KEY`, сам код там не хранится. Всем остальным
  сервер эти перчатки обрезает, что бы их игра ни прислала.

## Что было в 2.6

- **Боты в бою с людьми.** В общих комнатах командного боя сервер добирает каждую команду ботами до 5 бойцов.
  Боты появляются, когда в комнате двое живых игроков, или когда одиночка не дождался соперника и начал бой сам.
  Заходит человек: бот его команды уходит. Последний человек вышел: комната закрывается вместе с ботами.
  В бою с бомбой, в рейтинге и в «своей комнате» (имя комнаты игроки ввели сами) ботов нет.
- **Кто двигает ботов.** Сервер ведёт здоровье, счёт и возрождение ботов, как у людей, а ходят и стреляют они в игре
  одного из игроков («хозяин»): она сообщает серверу, где боты и в кого попали. Хозяин вышел или у него зависла
  игра: через несколько секунд ботов подхватывает игра другого игрока. Урон от ботов сервер считает на четверть
  слабее, чем от людей.
- **Пати.** У каждого игрока свой код из 5 знаков. Кто ввёл у себя код друга, попадает в его комнату и в его команду,
  какую бы комнату и сторону он ни выбрал (если там ещё есть место).

## Что в папке

| Файл | Зачем |
| --- | --- |
| `server.js` | сам сервер |
| `ratings.json` | рейтинг игроков: сервер создаёт этот файл сам, в архиве его нет |
| `.gitignore` | чтобы `ratings.json` не попал на GitHub и не затёрся при обновлении |
| `address.txt` | адрес сервера, который игра читает сама (нужно вписать свой IP) |
| `package.json` | чтобы работала команда `npm start` |
| `brick-strike.service` | автозапуск через systemd (по желанию) |

## Запуск

1. Залей эти файлы в новый **публичный** репозиторий на GitHub с именем **`brick-strike-server`**.
   Имя важно: игра ищет файл `address.txt` именно в репозитории `sabinalol1712-crypto/brick-strike-server`.
2. Зайди на сервер по SSH и скачай репозиторий:

   ```bash
   git clone https://github.com/ТВОЙ_ЛОГИН/brick-strike-server.git
   cd brick-strike-server
   ```

3. Проверь Node.js командой `node -v`. Если его нет: `sudo apt install -y nodejs`.
4. Запусти сервер:

   ```bash
   node server.js
   ```

   В окне появится строка «сервер слушает порт 3100».
5. Открой порт 3100 для входящих подключений (TCP):

   ```bash
   sudo ufw allow 3100/tcp
   ```

   Если в панели Hetzner включён Firewall, добавь там такое же правило: входящие, TCP, порт 3100.
6. Проверка: открой в браузере `http://IP_СЕРВЕРА:3100/`. Должна появиться надпись «сервер работает».

## Чтобы сервер не выключался

Если на сервере уже стоит pm2:

```bash
pm2 start server.js --name brick-strike
pm2 save
```

Без pm2 подойдёт systemd: инструкция в три строки лежит в начале файла `brick-strike.service`.

## Чтобы в игру заходили одной кнопкой

1. Открой на GitHub файл `address.txt`, нажми на карандаш и впиши в последнюю строку IP своего сервера вместо `0.0.0.0`.
2. Сохрани изменения (Commit changes). Через минуту-две игра начнёт видеть адрес.

После этого игроку достаточно нажать «Играть» в меню игры: игра сама прочитает адрес, подключится и найдёт бой.
Если IP сервера поменяется, достаточно поправить этот файл, новый APK собирать не нужно.

## Как зайти из игры

- «Играть» в главном меню ищет живых игроков: заходит туда, где они уже есть, или открывает общую комнату и ждёт.
  На экране поиска выбирается вид боя: «Бой» (командный), «Бомба» или «Рейтинг 2×2».
- В командном бою, если никого нет, через несколько секунд бой начинается с ботами, а люди заходят прямо в него.
- «Рейтинг 2×2» начинается только когда в комнате четверо, двое на двое. Пока игроков меньше, все ждут.
- «Сейчас играют» в углу меню: список боёв, которые идут прямо сейчас. Кнопка «Зайти» ведёт в выбранный бой.
- «Пати с другом» под кнопкой «Играть»: один даёт свой код, второй вводит его, и оба попадают в один бой и одну команду.

Имя игрока, свой сервер и своя комната: «Настройки» → «Имя и сервер». В своей комнате играют только те, кто ввёл
её имя: ботов там нет, и в списке «Сейчас играют» её не видно.

В матче:

- Чат: кнопка «ЧАТ» на телефоне, клавиши Y (всем) и U (команде) на компьютере. Есть готовые фразы.
- Скины на оружии видят все игроки в комнате. Оружие убитого лежит на земле со своим скином, его можно подобрать.
- После смерти можно смотреть глазами тиммейта (кнопка огня переключает игрока).

Онлайн работает в приложении для Android (APK). Со страницы игры на claude.ai подключиться к серверу
нельзя: браузер не пускает такие соединения с защищённой страницы.

## Счётчик онлайна

Под кнопкой «Играть» в главном меню написано, сколько людей сейчас в игре или онлайн. Это число считает сервер:
в него входят все, кто сейчас в комнатах, и все, у кого игра просто открыта (игра отмечается на сервере раз
в полминуты, отметка живёт чуть больше минуты). Один человек считается один раз. Пока сервер не запущен или его
адрес не вписан в `address.txt`, там написано «Поиск живых игроков».

## Правила

Командный бой:

- Спецназ против террористов, команды сервер выравнивает сам.
- Общие комнаты называются `arena-1`, `arena-2` и так далее: новая открывается, когда в прежних нет мест.
- Матч идёт до 50 убийств или 10 минут, потом через 12 секунд сам начинается новый.
- Возрождение через 3 секунды, первые 2 секунды после него игрок неуязвим.

Закладка бомбы (карта «Старый город», точка A):

- Раунды без возрождения до 5 побед, после 4 раундов команды меняются сторонами.
- Перед раундом 6 секунд заморозки, раунд длится 1 минуту 55 секунд.
- Закладка занимает 3,2 секунды, разминирование 6 секунд, бомба взрывается через 40 секунд.
- Зашедший посреди раунда выходит в бой со следующего. Раунд начинается, когда в обеих командах кто-то есть.

Рейтинг:

- Рейтинг меняют только матчи «Рейтинг 2×2» на сервере, то есть только игра против живых игроков. Матчи с ботами
  (в игре это тренировка) на него не влияют. У нового игрока 1000.
- За победу над сильными соперниками дают больше, за поражение от слабых снимают больше (от 8 до 32 за матч).
- Кто вышел из начатого рейтингового матча, получает поражение сразу, а матч продолжается без него.
  Если команда вышла целиком, оставшимся засчитывается победа.
- Таблица лучших: кнопка «Топ» в игре. В неё попадают те, кто сыграл хотя бы один рейтинговый матч.
- Свой рейтинг игра показывает и в главном меню: сервер сообщает его вместе со счётчиком онлайна.
- Рейтинг хранится в файле `ratings.json` рядом с `server.js`. Не удаляй его при обновлении сервера.
  На бесплатных хостингах, где диск стирается при перезапуске, рейтинг будет сбрасываться.

Оружие в онлайне бесплатно (кнопка «Оружие» или клавиша B; в раундах с бомбой его меняют в начале раунда),
но у каждой стороны оно своё, как в CS. Только у террористов: Glock-18, Tec-9, MAC-10, Sawed-Off, Galil AR, AK-47,
SG 553, G3SG1. Только у спецназа: USP-S, P2000, Five-SeveN, MP9, MAG-7, FAMAS, M4A4, M4A1-S, AUG, SCAR-20.
Остальное есть у обеих сторон. При смене сторон игра сама выдаёт ближайшую замену (AK-47 ↔ M4A4 и так далее).
Ствол другой стороны можно только подобрать с земли: он остаётся у игрока до смерти (в раундах до конца раунда).

## Настройки

Задаются переменными перед запуском:

| Переменная | Что меняет | По умолчанию |
| --- | --- | --- |
| `PORT` | порт сервера | 3100 |
| `KILLS` | до скольки убийств идёт матч (5–500) | 50 |
| `MINUTES` | сколько минут длится матч (2–60) | 10 |
| `ROOM_SIZE` | сколько игроков помещается в комнату (2–16) | 10 |
| `BOTS` | до скольки бойцов боты добирают каждую команду (0–8; 0: без ботов) | 5 |
| `ROUNDS` | до скольки побед идёт матч с бомбой (2–16) | 5 |
| `RATINGS` | где лежит файл с рейтингом | `ratings.json` рядом с сервером |

Пример: `PORT=4000 KILLS=30 BOTS=4 node server.js`

## Проверка и обновление

- `http://IP_СЕРВЕРА:3100/status` показывает комнаты, их режим, число игроков в матчах и общий онлайн.
- Обновление: залей новый `server.js` на GitHub, на сервере выполни `git pull` и перезапусти сервер
  (`pm2 restart brick-strike` или `sudo systemctl restart brick-strike`).
- Если вышла новая версия игры с пометкой «нужен новый сервер», обнови и сервер: старый откажет во входе.
- Новый сервер заменяет прежний целиком: достаточно положить новый `server.js` на место старого и перезапустить.
  Свой `address.txt` с вписанным IP при этом не заменяй: в архиве лежит пустой образец.
